# 🚀 GCP Data Engineering Quick Trigger Sheet

### 🔹 Spark / Hadoop cluster? → **Dataproc**

### 🔹 Streaming / ETL pipeline? → **Dataflow**

### 🔹 Workflow scheduling / DAGs? → **Composer**

### 🔹 Data cleaning UI tool? → **Dataprep**

---

### 🔹 Data warehouse / Analytics SQL? → **BigQuery**

### 🔹 Massive fast SQL analytics? → **BigQuery**

### 🔹 Aggregated data sharing securely? → **Authorized Views (BigQuery)**

### 🔹 Row-level security? → **BigQuery Row Access Policies**

### 🔹 Column-level security? → **BigQuery Column-level Security**

---

### 🔹 Object storage (files, backups, raw data)? → **Cloud Storage**

### 🔹 NoSQL wide-column database? → **Bigtable**

### 🔹 Globally distributed relational database? → **Cloud Spanner**

### 🔹 Managed MySQL/PostgreSQL? → **Cloud SQL**

### 🔹 Serverless NoSQL document DB? → **Firestore**

---

### 🔹 Real-time messaging / event ingestion? → **Pub/Sub**

### 🔹 Data transfer from SaaS (Google Ads, YouTube etc.)? → **BigQuery Data Transfer Service**

### 🔹 Hybrid / on-prem data transfer? → **Transfer Appliance**

---

### 🔹 Metadata management / data cataloging? → **Data Catalog**

### 🔹 Data governance & discovery? → **Dataplex**

### 🔹 Monitor data quality? → **Dataplex Data Quality**

---

### 🔹 Machine Learning model training (managed)? → **Vertex AI**

### 🔹 SQL-based ML inside warehouse? → **BigQuery ML**

---

# 🧠 Ultra Memory Formula

* Store file? → **Cloud Storage**
* Store structured analytics? → **BigQuery**
* Move/Stream data? → **Pub/Sub + Dataflow**
* Run Spark? → **Dataproc**
* Schedule pipelines? → **Composer**
* Clean data visually? → **Dataprep**
